# H&M 구매 데이터 기반 30일 재구매 분석

패션 커머스 고객의 재구매 특성을 이해하기 위한 개인 분석 프로젝트입니다.
Kaggle의 H&M 구매 데이터를 이용해 전체·월별·첫 구매일 채널별
30일 재구매율을 비교했습니다.

H&M 공개 데이터로 진행했으며, 에이블리의 실제 고객 데이터나
서비스 성과를 나타내지 않습니다.

## 분석 질문

- 처음 구매가 관측된 고객 중 30일 안에 다시 구매한 비율은 얼마인가?
- 첫 관측 구매 월에 따라 재구매율이 다른가?
- 첫 관측 구매일에 이용한 채널에 따라 재구매율이 다른가?

## 데이터

- 출처: Kaggle, H&M Personalized Fashion Recommendations
- 거래 관측 기간: 2018-09-20 ~ 2020-09-22
- 거래 데이터: 31,788,324행
- 최종 분석 고객: 1,338,029명
- 사용 파일: transactions_train.csv, customers.csv, articles.csv

원본 데이터와 고객별 결과 파일은 저장소에 포함하지 않았습니다.
원본은 Kaggle에서 이용 조건을 확인하고 내려받아야 합니다.

## 지표 정의

30일 재구매율 =
첫 관측 구매일 다음 날부터 30일째까지 다시 구매한 고객 수
÷ 분석 대상 고객 수 × 100

- 같은 날 여러 상품을 구매한 것은 재구매로 계산하지 않았습니다.
- 첫 구매 이후 30일을 모두 관찰할 수 있는 고객만 포함했습니다.
- 재구매는 채널과 관계없이 인정했습니다.
- 첫 관측 구매가 실제 생애 첫 구매를 의미하지는 않습니다.

## 주요 결과

| 분석 대상 | 30일 재구매율 |
|---|---:|
| 전체 분석 고객 | 28.13% |
| 2019년 이후 첫 관측 구매 고객 | 21.81% |
| 첫 구매일 채널 1만 이용 | 29.87% |
| 첫 구매일 채널 2만 이용 | 27.04% |
| 첫 구매일 두 채널 모두 이용 | 48.62% |

분석 대상 기간과 고객 구성에 따라 결과가 달라졌습니다.
채널별 차이는 관찰된 관계이며, 채널 이용의 인과효과를 의미하지 않습니다.
채널 번호의 실제 의미는 공식 정의 확인 전까지 번호로 표기했습니다.

## 데이터 검증 사례

2020년 4월 첫 관측 고객이 모두 채널 2로 분류되었습니다.
기존 고객을 포함한 원본 거래를 다시 집계한 결과,
해당 월의 채널 1 거래가 0행임을 확인했습니다.

결과가 예상과 다를 때 원본 데이터와 대조하는 과정을 거쳤습니다.

## 사용 기술

- Python
- pandas: 데이터 검증, 고객별 처리, 집계
- Matplotlib: 결과 시각화
- 거래 CSV를 10만 행씩 나누어 처리

## 실행 방법

1. Python 가상환경을 만들고 활성화합니다.
2. 필요한 패키지를 설치합니다.

```powershell
python -m pip install -r requirements.txt
```

3. 원본 CSV 3개를 `data/raw/`에 넣습니다.
4. 프로젝트 최상위 폴더에서 번호순으로 Python 파일을 실행합니다.

- 01~04: 데이터 구조 및 품질 검증
- 05: 고객별 첫 관측 구매일 계산
- 06: 30일 재구매 여부 및 전체 재구매율 계산
- 07: 월별 재구매율 집계
- 08: 월별 결과 시각화
- 09: 첫 구매일 채널별 재구매율 집계
- 10: 월별·채널별 원본 거래 행 수 확인

집계 결과는 `data/processed/`,
그래프는 `outputs/figures/`에 저장됩니다.

## 한계 및 활용 제안

데이터 시작 이전의 구매 이력을 알 수 없어 실제 신규 고객을
정확히 구분할 수 없습니다. 고객 구성과 시기 차이도 결과에
영향을 줄 수 있습니다.

향후에는 첫 구매 후 재구매하지 않은 고객을 대상으로 추천 메시지
발송 여부를 무작위 배정하고, 재구매율을 비교하는 실험을 제안합니다.
이 실험은 아직 실행하지 않았습니다.
