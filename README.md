# H&M 30일 재구매 분석

**Python · pandas · Matplotlib | 고객 구매 행동 분석**

H&M 공개 구매 이력을 활용해 **첫 구매가 관측된 고객이 30일 이내 다시 구매하는 비율**을 분석했습니다. 전체 평균뿐 아니라 첫 관측 구매 시점과 구매 채널에 따른 차이를 비교하고, 해석이 어려운 결과는 원본 거래 데이터로 재확인했습니다.

[상세 분석 보고서 (PDF)](report/hm_repurchase_portfolio.pdf) · [재구매율 계산 코드](06_purchase_rate.py)

## 1. 분석 질문

- 첫 관측 구매 이후 30일 안에 재구매한 고객 비율은 얼마인가?
- 첫 관측 구매 시기에 따라 재구매율이 달라지는가?
- 첫 구매일에 이용한 채널에 따라 차이가 있는가?

## 2. 데이터와 계산 기준

| 항목 | 내용 |
|---|---|
| 출처 | Kaggle - H&M Personalized Fashion Recommendations |
| 거래 관측 기간 | 2018-09-20 ~ 2020-09-22 |
| 거래 데이터 | 31,788,324행 |
| 분석 대상 | 30일 관찰 기간이 확보된 고객 1,338,029명 |
| 주요 도구 | Python, pandas, Matplotlib |

**30일 재구매율** = 첫 관측 구매일 다음 날부터 30일째까지 다시 구매한 고객 수 / 분석 대상 고객 수 × 100

- 첫 관측 구매일 당일의 여러 거래는 재구매로 세지 않았습니다.
- 관측 종료일을 고려해 첫 관측 구매일이 **2020-08-23까지**인 고객만 포함했습니다.
- 고객당 한 번 이상 재구매했더라도 한 명으로 계산했습니다.
- 원본에 주문 ID가 없어 **거래 행 수와 주문 수는 다르게 해석**했습니다.
- 데이터 시작 이전 구매 이력은 알 수 없으므로 **'첫 관측 구매 고객'을 실제 신규 고객으로 간주하지 않았습니다.**

## 3. 주요 결과

| 비교 대상 | 분석 고객 수 | 30일 재구매율 |
|---|---:|---:|
| 전체 분석 대상 | 1,338,029명 | **28.13%** |
| 2018년 9월 첫 관측 고객 제외 | 1,197,689명 | 26.15% |
| 2019년 이후 첫 관측 고객 | 756,843명 | 21.81% |

**고객군의 범위에 따라 평균이 달라졌습니다.** 전체 재구매율 28.13%만 보면 2019년 이후 첫 관측 고객군의 21.81%와 차이가 있다는 점을 놓칠 수 있습니다. 관측 초기에 이미 구매 경험이 있던 고객이 포함되었을 가능성도 있어, 특정 기간이 더 '정확하다'고 판단하지 않았습니다.

### 첫 관측 구매일 채널별 비교

| 고객군 | 고객 수 | 30일 재구매율 |
|---|---:|---:|
| 채널 1만 이용 | 460,403명 | 29.87% |
| 채널 2만 이용 | 870,512명 | 27.04% |
| 두 채널 모두 이용 | 7,114명 | 48.62% |

채널 1과 채널 2의 재구매율 차이는 **2.83%p**였습니다. 두 채널 이용 고객군은 재구매율이 높았지만, 고객군의 기존 활동성이나 관측 시기 차이가 섞여 있을 수 있어 **채널 자체의 효과로 단정하지 않았습니다.** 채널 번호의 정확한 비즈니스 의미도 별도로 확인되지 않았습니다.

### 원본 재검증 사례

2020년 4월 채널 1의 첫 관측 고객이 나타나지 않아, 해당 월 원본 거래를 채널별로 다시 집계했습니다. 실제로도 **2020년 4월 채널 1 거래는 0행**이었으며, 분석 결과와 원본 분포가 일치함을 확인했습니다. 다만 거래가 관측되지 않은 원인은 알 수 없습니다.

## 4. 해석의 한계와 후속 검증

- 데이터 관측 시작 이전의 구매 이력이 없어 **실제 신규 고객을 구분할 수 없습니다.**
- 채널별 재구매율 차이는 계절성·고객 구성 등과 관련될 수 있으며 **인과관계를 입증하지 않습니다.**
- 후속 실험에서는 첫 관측 구매 후 7일간 재구매하지 않은 메시지 수신 동의 고객을 무작위로 나누어 추천 메시지의 추가 발송 여부를 비교할 수 있습니다. 주 지표는 첫 관측 구매 후 8~30일 동안의 재구매 여부로 설정하되, 해당 실험은 **실제로 진행하지 않은 제안**입니다.

## 5. 분석 코드와 실행 안내

분석 코드는 **Python과 pandas**로 작성했으며, 시각화에는 Matplotlib를 사용했습니다. 스크립트는 `01_check_data.py`부터 `10_check_channel_activity.py`까지 순서대로 실행합니다.

데이터는 [Kaggle H&M Personalized Fashion Recommendations](https://www.kaggle.com/competitions/h-and-m-personalized-fashion-recommendations/data)에서 내려받습니다. 원본 CSV(`articles.csv`, `customers.csv`, `transactions_train.csv`)를 `data/raw/`에 두고 실행합니다. 원본 데이터의 재배포 조건을 확인해 직접 업로드하지 않았습니다. 대용량 거래 CSV는 10만 행 단위로 나누어 처리했습니다.

**핵심 결과는 공개 데이터를 재분석한 개인 프로젝트의 결과이며, 실제 서비스를 대상으로 실시한 실험 성과가 아닙니다.**
